# Horizon Xbox UWP shell preview

This folder contains the UWP page resources copied into the starter project during CI.

## Included in this milestone
- TV-sized Home, Input Test and About screens.
- Focusable XAML buttons for keyboard, mouse and Xbox controller navigation.
- Live Windows.Gaming.Input readings for controller buttons, sticks and triggers.
- CoreWindow keyboard diagnostics and pointer diagnostics.

## Not included
This is not the Horizon game engine or an Android-to-UWP conversion. The Horizon Rust engine has not been ported or linked to this UWP project. This shell cannot launch Minecraft yet. A Windows/Xbox engine port requires separate renderer, input, filesystem, networking and platform integration work.
